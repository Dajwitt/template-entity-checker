# Requirements

## Runtime

| Requirement | Version/status |
|---|---|
| Home Assistant | 2026.7.3 or newer |
| HACS | 2.0.0 or newer for HACS installation |
| YAML configuration | neither required nor supported |

## Integration

| Property | Value |
|---|---|
| Integration type | `service` |
| IoT class | `local_polling` |
| Config Flow | yes |
| Config Entries | exactly one |
| Dependencies | `persistent_notification`, `template` |
| Platform | `sensor` |
| Expected entity | `sensor.template_entity_checker` |

## Languages

English and German user-interface translations are included.

## Release status

| Version | Status |
|---|---|
| `0.1.2` | current public stable version |
| `0.1.1` | previous stable version |

A normal HACS installation offers `0.1.2` as the current stable version.
